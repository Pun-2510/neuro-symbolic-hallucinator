UX/UI Concept Specification

SourceLogic — Academic Source Verification Workspace

Extract citations. Resolve references. Verify academic sources.

Concept thiết kế tổng thể cho website kiểm tra citation và reference trong tài liệu học thuật, truy xuất metadata từ các nguồn học thuật, so khớp nguồn và sử dụng Neuro-Symbolic Logic Checker để phát hiện metadata error, source mismatch, nguồn có khả năng hallucinated và các trường hợp không thể xác minh.

Định vị sản phẩm: đây không phải hệ thống chấm điểm tiểu luận. Hệ thống tập trung vào citation/reference extraction, citation-reference linking, academic metadata retrieval, candidate matching và explainable verification.

1. Product Vision

Website nên được thiết kế như một Academic Source Verification Workspace, không phải một dashboard AI phổ thông. Giá trị cốt lõi của UX là cho phép người dùng đi từ: 

Document
  ↓
Citation Extraction
  ↓
Reference Extraction
  ↓
Citation ↔ Reference Linking
  ↓
Academic Metadata Retrieval
  ↓
Candidate Matching
  ↓
Neuro-Symbolic Verification
  ↓
Explainable Decision

Mọi kết luận quan trọng phải có khả năng truy ngược về evidence và logic rule.

2. Mental Model: “Debugger cho citation”

Mental model phù hợp nhất là một IDE/debugger dành cho academic integrity:

  • Document = source code
  • Citation = reference call
  • Bibliography/reference list = dependency registry
  • Academic databases = external source providers
  • Neuro-symbolic checker = linter/static analyzer
  • Issues = diagnostics
  • Logic trace = execution/debug trace
Trọng tâm UX: hệ thống không chỉ nói “reference sai”, mà phải cho thấy sai ở đâu, candidate nào được tìm thấy, metadata nào khác nhau và rule nào dẫn tới kết luận.

11. Verification Status Taxonomy

VERIFIED Publication phù hợp và metadata nhất quán.

LIKELY VERIFIED Candidate mạnh nhưng thiếu một số identifier như DOI.

METADATA ERROR Source tồn tại nhưng citation có metadata sai.

SOURCE MISMATCH Citation có vẻ trỏ đến publication khác.

LIKELY HALLUCINATED Không tìm được nguồn đủ tương đồng qua nhiều database.

UNVERIFIABLE Không đủ dữ liệu để kết luận.

Cần tách rõ Hallucinated và Metadata Error. Đây là hai loại vấn đề khác nhau về bản chất.

22. MVP Priorities

1. Landing

Giải thích rõ hệ thống dùng để kiểm tra citation/reference.

2. New Check

Upload tài liệu và chọn citation style.

3. Processing

Hiển thị pipeline extraction, retrieval và verification.

4. Report

Tổng quan verified, metadata error, mismatch, hallucinated, unverifiable.

5. Reference Inspector

So sánh citation metadata với retrieved metadata.

6. Logic Trace

Explainable reasoning và symbolic rule trace.

Nguyên tắc cốt lõi cho coding agent:
Không thiết kế sản phẩm như một essay grader. Không thêm các chức năng grammar scoring, argument scoring hoặc essay grade nếu không có yêu cầu mới. Mọi màn hình phải phục vụ một trong các mục tiêu: extract, link, retrieve, compare, verify, explain.
